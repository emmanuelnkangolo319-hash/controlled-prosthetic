# controlled-prosthetic
it is a prosthetic hand that is controlled by buttons on a glove, contrary to the more complicated methods of controlling prosthetics.
im am using cheap things to make this, mainly because i dont like spendig money but also to cut costs drastically compared to 
The expensive prosthetic hands. Now, im not going to tell you that mine are better, but they certainly will be cheaper, and allow the user to atleast have a hand that works for a good price.
